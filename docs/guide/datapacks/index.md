# Datapacks

World of Pannotia ships a set of datapacks that change recipes, loot, commands and tracking. They are loaded automatically for every world by the Global Packs mod, so you do not need to install or enable anything, and they apply to existing worlds too. Most are passive; a few add `/trigger` commands or an item you use.

| Datapack | Summary | How you interact |
|---|---|---|
| [AFK Display](afk-display.md) | Idle players' names turn grey | Passive |
| [Armor Statues](armor-statues.md) | Command book to pose armor stands and hide item frames | Item (sign a Book and Quill "Statues") + `/trigger` |
| [Back](back.md) | Return to where you last teleported from | `/trigger back` |
| [BACAP](bacap.md) | About 1,200 extra advancements with rewards and trophies | Advancements screen (L); config via `/function` |
| [BACAP Torture Edition](bacap-torture-edition.md) | Extreme completionist add-on for BACAP | Advancements screen; optional `/function` |
| [Homes](homes.md) | Save and teleport to homes | `/trigger sethome`, `home`, `homes`, `namehome`, `delhome` |
| [More Effective Tools](more-effective-tools.md) | Glass, beds, lamps and more break faster with the right tool | Passive |
| [Silence Mobs](silence-mobs.md) | Mute a mob with a renamed name tag | Item (name tag "Silence me") |
| [Spawn](spawn.md) | Teleport to spawn | `/trigger spawn` |
| [Track Raw Statistics](track-raw-statistics.md) | 100+ raw `ts_` stat scoreboards | Operator commands |
| [Track Statistics](track-statistics.md) | Processed `hc_` stat scoreboards (play time, ores, elytra) | Operator commands |
| [Vanilla Tweaks Crafting Tweaks](vanillatweaks.md) | More stairs/trapdoors per craft, colour swapping, unpacking, blackstone recipes | Passive (crafting) |
| [Villager Workstation Highlights](villager-workstation-highlights.md) | Show a villager's job site | `/trigger vwh_findStation` |
| [Wandering Trader Announcements](wandering-trader-announcements.md) | Chat alert when a wandering trader is nearby | Passive |
| [Wandering Trades (Hermit Edition)](wandering-trades-hermit-edition.md) | Traders sell Hermit and Mini block heads | Trade with a wandering trader |
| [World of Pannotia](world-of-pannotia.md) | Mob heads, Mini blocks, dragon/husk/shulker drops, block drops, beacon bases, recipes | Passive / stonecutter / crafting |

Teleport packs work together: [Homes](homes.md) and [Spawn](spawn.md) save your position so [Back](back.md) can return you.
