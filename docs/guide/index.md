# World of Pannotia: Player Guide

World of Pannotia is a Fabric modpack for **Minecraft 26.2** (pack version 18.x). It stays close to vanilla. There are no new dimensions or tech trees. Instead, about 200 mods and a set of datapacks smooth out everyday play, add decorative and storage blocks, make villagers, enchanting, farming and exploration less tedious, and give you plenty of maps, tooltips and HUD information.

This guide explains what is different from vanilla and how to use it.

> [!NOTE]
> This guide was generated from the pack's actual mod jars, datapacks and config files. It was then verified section by section, but a few details are marked *(unverified)* where the sources were thin. If something in game doesn't match, the game is right. Please report it.
