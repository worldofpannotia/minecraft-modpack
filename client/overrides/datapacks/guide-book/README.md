# Guide Book

Gives every player the World of Pannotia in-game guide (an Opus book, see `client/overrides/resourcepacks/pannotia-guide`).

* `pannotia_guide:welcome` is an advancement that triggers once on the first tick after a player joins and runs
  `pannotia_guide:give_guide`, which gives `opus:book` with `opus:book_id={book_id:"pannotia:pannotia"}`.
* `pannotia_guide:guide_book` is a shapeless recipe (book + compass) to craft a replacement.

Not yet tested in game.
