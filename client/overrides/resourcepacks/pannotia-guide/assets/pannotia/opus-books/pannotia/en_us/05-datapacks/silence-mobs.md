# Silence Mobs

Name a mob with a name tag reading "Silence me" to stop it making sounds, and "Unsilence me" to restore its sound.

## How to use

1. Rename a Name Tag in an anvil to `Silence me` (also accepted: `silence me`, `Silence Me`, `silence_me`).
2. Use it on the mob.

To undo, use a name tag named `Unsilence me` (also `unsilence me`, `Unsilence Me`, `unsilence_me`).

| Name tag text | Effect |
|---|---|
| Silence me | Mob becomes Silent |
| Unsilence me | Mob can make sound again |

## What it changes

The nearest mob with that name within 16 blocks becomes Silent. It glows for 3 seconds with a chime and is briefly named "silenced". The name is removed after about 3 seconds.

## Notes

- The mob ends up unnamed afterwards, so a silenced mob cannot keep a custom name through this pack.
- Handy for noisy farm animals or villagers. Related mod: Extreme Sound Muffler (see [Cosmetic, Visual & Audio](../04-mods/16-cosmetic-visual-and-audio.md)).
