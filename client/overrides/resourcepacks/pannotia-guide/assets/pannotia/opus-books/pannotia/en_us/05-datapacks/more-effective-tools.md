# More Effective Tools

Gives blocks that normally have no proper tool a "correct tool", so they break faster with it. Glass, lamps and skulls become pickaxe blocks, beds and candles become axe blocks, and so on. Fully automatic.

## How to use

Nothing to do; use the matching tool.

## What it changes

| Tool | Blocks added |
|---|---|
| Pickaxe | Glass, glass panes, tinted glass, all stained glass and stained glass panes; beacon; glowstone; sea lantern; redstone lamp; lever; frosted ice; ochre, verdant and pearlescent froglight; creeper, dragon, piglin, zombie, player, skeleton and wither skeleton heads/skulls (floor and wall) |
| Axe | All beds, all candles, cactus, honeycomb block |
| Hoe | Wool carpets |
| Shovel | Cake and candle cakes |

Only block tags change; drops are unchanged (glass still needs Silk Touch to drop). Blocks intended to have no effective tool (powder snow, reinforced deepslate, vault) are deliberately excluded.
