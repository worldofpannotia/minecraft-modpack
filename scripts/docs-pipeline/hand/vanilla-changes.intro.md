# What's different from vanilla

Every change this pack makes to vanilla recipes, drops and behavior, collected from all mods and datapacks. Each row links to the page with the full details. Purely additive content, such as new blocks, is in the [items index](items-index.md) instead.

> [!TIP]
> In game, **REI** shows the recipes that are actually active. If a recipe here and REI disagree, trust REI.

Pack-wide config tweaks (stack sizes, right-click harvest, villager behavior and so on) are summarized on the [Quality of Life page](mods/quality-of-life.md#pack-wide-tweaks).
