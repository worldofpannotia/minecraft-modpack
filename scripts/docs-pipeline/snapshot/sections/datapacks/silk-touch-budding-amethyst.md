# Silk Touch Budding Amethyst

Budding amethyst can be harvested with a Silk Touch tool, so you can move it, for example to build an amethyst farm.

## How to use

Mine budding amethyst in an amethyst geode with a Silk Touch pickaxe.

## What it changes

| Block | Tool | Drop |
|---|---|---|
| Budding Amethyst | Silk Touch (level 1+) | 1 Budding Amethyst |
| Budding Amethyst | Anything else | Nothing (same as vanilla) |

## Notes

- The World of Pannotia datapack ([world-of-pannotia.md](world-of-pannotia.md)) contains the same change; the two overlap harmlessly.
